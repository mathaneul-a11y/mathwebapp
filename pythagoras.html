수학 탐구실: 피타고라스 정리와 두 점 사이의 거리 중·고등 수학

직교좌표계에서 직각삼각형을 작도하여 거리 공식 d = √[(x₂ - x₁)² + (y₂ - y₁)²] 을 시각적으로 이해해 보세요.

인터랙티브 직교좌표계 (모눈종이)

🖱️ 마우스나 손가락으로 점 A와 점 B를 드래그하세요
점 A: (0, 0)
점 B: (3, 4)
직각점 C: (3, 0)
🚀 탐구 미션 & 추천 배치
📊

실시간 피타고라스 계산판

단계별 유도
STEP 1. 직각삼각형의 두 변의 길이 구하기 절댓값 |차이|
가로 길이 (밑변 a)
|x₂ - x₁| = |3 - 0| = 3
세로 길이 (높이 b)
|y₂ - y₁| = |4 - 0| = 4
STEP 2. 피타고라스 정리 (a² + b² = c²) 적용 빗변의 제곱
(가로)² + (세로)² = (빗변)²
3² + 4² = 9 + 16 = 25

빗변의 제곱(c²)이 25이므로, 빗변 c = √25 입니다.

STEP 3. 두 점 A와 B 사이의 거리 (d) 거리 공식 유도 완성
d = √[(x₂ - x₁)² + (y₂ - y₁)²]
d = √25
거리 d = 5
(정수 정확값)
💡

핵심 연결고리: 교과서의 복잡해 보이는 '두 점 사이의 거리 공식'은 사실 '직각삼각형의 빗변을 구하는 피타고라스 정리'와 완전히 같은 식입니다!

🤔

수업용 탐구 질문 상자 (선생님 & 학생 토론 활동)

질문 카드를 클릭하면 생각거리와 정답 해설이 펼쳐집니다

좌표평면에서는 격자선이 가로축(x축)과 세로축(y축)으로 서로 수직(90°)으로 교차합니다.

  • 비스듬히 기울어진 선분의 길이는 눈금자로 직접 재기 어렵습니다.
  • 하지만 가로 길이(x좌표 차이)와 세로 길이(y좌표 차이)는 눈금의 차이로 아주 쉽게 셀 수 있습니다.
  • 가로선과 세로선은 언제나 수직을 이루므로, '직각삼각형'을 만들면 피타고라스 정리를 이용해 비스듬한 선분의 길이를 정확히 계산할 수 있기 때문입니다!

두 식은 기호만 다를 뿐 100% 동일한 식입니다.

• 밑변 a = |x₂ - x₁|  →  a² = (x₂ - x₁)²
• 높이 b = |y₂ - y₁|  →  b² = (y₂ - y₁)²
• 빗변 c = 거리 d  →  c² = d²

피타고라스 정리 a² + b² = c² 에 대입하면:
(x₂ - x₁)² + (y₂ - y₁)² = d² 이 되고, 양변에 제곱근(루트)을 씌우면 우리가 교과서에서 외우던 거리 공식 d = √[(x₂ - x₁)² + (y₂ - y₁)²] 이 완성됩니다!
